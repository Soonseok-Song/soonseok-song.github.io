# RHL Lab Website

Website source for the RHL research group, Inha University.

**Live site:** https://soonseok-song.github.io

## Structure

| Path | What it is |
|---|---|
| `*.html` | Page content — one file per page |
| `css/` | Stylesheet |
| `images/` | Images and short looping videos |
| `data/` | Publication and member lists (JSON) |

Changes pushed to `main` are published automatically.

## Not in this repository

Working files (pptx, drafts, original photos, notes) are kept outside this
repository and are never published. See `.gitignore`.

Work in progress.
